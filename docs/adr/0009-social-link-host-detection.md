# ADR 0009: 外部リンクのサービスは URL のホストで判定する

- **Date**: 2026-10-15
- **Status**: Accepted

## Context

GitHub や DevIO などの外部リンクには、サービスごとのアイコンを付けて表示したい。

当初はサービス名を自由入力のカラム(`service`)で持っていた。フロントはこの文字列を見てアイコンを選ぶことになるが、`Github` と `GitHub` のような入力の揺れでアイコンが出なくなる。

## Decision

`SocialLink` はサービス名のカラムを持たず、`url` だけを持つ。

- 登録時: Zod で URL のホストを許可リストと照合する。リストにないホスト(例: タイプミスの `glthub.com`)はバリデーションエラーにして、登録できないようにする
- 表示時: URL のホストから、アイコンと表示名を決める

許可リストはバックエンド(Zod)とフロント(アイコン)の両方で使うので、共通の定数として持つ。

```ts
const SOCIAL_SERVICES = {
  'github.com': { label: 'GitHub' },
  'dev.classmethod.jp': { label: 'DevIO' },
  // ...
} as const
```

### 検討した選択肢

| 案 | 内容 | 採否 |
|----|------|------|
| A | URL のホストで判定し、許可リスト外は登録させない | 採用 |
| B | サービス名を自由入力で持つ | 不採用(入力の揺れでアイコンが出なくなる) |
| C | サービスの種別キー(`github` など)を別カラムで持つ | 不採用(URL と種別が食い違う入力ができてしまう) |

## Consequences

- URL のタイプミスを登録時に防げる
- 許可リストにないサイト(個人ブログなど)は登録できない。必要になったらリストにホストを追加する
